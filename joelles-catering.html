Joelles Catering

A website for a Kenyan catering business.

A look at the website

Real mobile views of the live Joelles Catering website.

What the client needed

Joelles Catering needed a website where customers could explore the menu, place orders, leave reviews, book catering, and request quotes.

About the project

The website introduces Joelle’s Catering Services and helps visitors explore catering options for weddings, birthdays, corporate events, and other celebrations.

My role

I designed and built the complete Joelles Catering website, including the frontend and backend. My work covered the page layouts, menu presentation, booking process, ordering features, customer reviews, and quote requests.

Website features

  • Catering services and menu pages
  • A gallery of event and catering photos
  • Quote requests and event booking options
  • Contact links for phone, email, and WhatsApp

Tools used

HTML · CSS · JavaScript
